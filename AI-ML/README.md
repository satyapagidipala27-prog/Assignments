# AI/ML Assignments — 6-Week Practical Track

This directory contains six weekly Python assignments covering foundational data analysis, supervised learning, model evaluation, and unsupervised learning.

## Weekly assignments

| Week | Topic | Project |
|---|---|---|
| 01 | Python for AI | Intelligent Application Log Analyzer |
| 02 | NumPy and pandas | Sample Superstore Business Sales Analysis |
| 03 | Mathematics and Statistics | House Price Prediction — NumPy Linear Regression vs Scikit-learn |
| 04 | Machine Learning Workflow | Customer Churn Prediction |
| 05 | Model Evaluation and Improvement | Churn Model Cross-Validation, Hyperparameter Tuning and Threshold Optimization |
| 06 | Unsupervised Learning | Customer Segmentation and Anomaly Detection using RFM, K-Means, PCA and Isolation Forest |

## Running the assignments

The scripts were authored for Google Colab. Some assignments use Colab-specific features such as `google.colab.files` and dataset paths under `/content`. Open the corresponding notebook/script in Colab, upload the required local datasets where applicable, and run the assignment.

### Datasets used

- **Week 01:** Creates a sample application log dataset.
- **Week 02:** Sample Superstore CSV (expected at `/content/Sample_Superstore.csv`).
- **Week 03:** California Housing dataset via scikit-learn.
- **Week 04–05:** IBM Telco Customer Churn CSV (expected at `/content/WA_Fn-UseC_-Telco-Customer-Churn.csv`).
- **Week 06:** UCI Online Retail dataset, downloaded by the script.

## Main libraries

Python, NumPy, pandas, Matplotlib, Seaborn, scikit-learn and joblib.

> These are learning assignments. Review each script's dataset path and dependencies before running it in a different environment.
